# СберИндекс: прогноз расходов и сигналы изменений

Решение прогнозирует средние безналичные расходы муниципалитетов на 1–3 месяца, строит интервалы прогноза и выделяет необычные изменения после поступления новых данных.

**[Полный отчёт — PDF](deliverables/hackathon_report_latex/main.pdf)** · [Все эксперименты и гипотезы](reports/all_experiments_and_hypotheses.md)

## Методология

Используем панель из **2 016 муниципалитетов за январь 2023 — декабрь 2024 года**: общие расходы и пять категорий. Логарифм позволяет сопоставлять относительные изменения территорий разного масштаба. Общую динамику отделяем от локальной; общий фактор прогнозируем сезонным значением с EMA годового изменения.

Локальные прогнозы дают **Chronos-Bolt, pooled Ridge и сезонная модель**. Ridge использует историю категорий, их доли, макроэкономические показатели, региональные цены и зарплаты. В фиксированном варианте ансамбля веса компонентов составляют **40/20/40**. На каждом моменте выпуска прогноза обучение использует только наблюдавшуюся историю.

Интервалы проверены на ансамбле с равными весами. Conformal-квантиль берём из завершённых ошибок; в адаптивном варианте масштаб зависит от прошлых ошибок муниципалитета. Границы объясняются формулой `прогноз × exp(±квантиль × масштаб)`. Детектор Page-Hinkley анализирует нормированные локальные ошибки после поступления факта. Сигнал выделяет муниципалитет для разбора по категориям и экономическому контексту.

## Результаты

| Проверка | Результат |
|---|---:|
| MAE ансамбля 40/20/40, выпуски июня–сентября 2024 | **702,7 руб.** |
| MAE того же ансамбля, выпуски октября–ноября 2024 | **835,0 руб.** |
| Рост ошибки при смене периода | **18,8%** |
| Покрытие глобального 90% интервала, два периода | **93,2% / 89,5%** |
| Покрытие адаптивного 90% интервала, два периода | **92,2% / 87,9%** |
| Сокращение средней ширины адаптивного интервала | **8,9% / 12,7%** |
| Обнаружение добавленного скачка, Page-Hinkley | **96,2%** |
| Фоновые уведомления на 100 МО-месяцев | **2,8** |

Точность, интервалы и обнаружение изменений оцениваются отдельно. Основной период содержит горизонты 1–3, поздний — 1–2. У внешних историй зафиксированы версии и принятые задержки. Статистические сравнения сохраняют эффект, доверительный интервал, p-value и поправку Холма; единицы анализа — временные блоки или панели симуляции. Подробности: [воспроизведение и статистика](docs/REPRODUCIBILITY.md).

## Запуск

Python **3.11**. Команды выполняются из корня репозитория.

```bash
python -m venv .venv
# Windows: .venv\Scripts\activate
# Linux/macOS: source .venv/bin/activate
python -m pip install -r requirements.txt
python scripts/reproduce.py --mode cached --detection
```

Этот запуск пересчитывает метрики, три способа построения интервалов на четырёх уровнях и тест детекторов по сохранённым прогнозам. `results/reproduction_checks.json` содержит проверку совпадения с отчётом. Исходные данные и эталонные результаты включены в репозиторий; соединение с сетью для этого режима не нужно после установки пакетов.

Повторное обучение финальной модели:

```bash
python scripts/prepare_checkpoint.py
python scripts/reproduce.py --mode fit --detection
```

Веса Chronos-Bolt скачиваются в зафиксированной ревизии и проверяются по SHA-256. При наличии локальных весов повторная загрузка не нужна. Для короткой проверки одного выпуска: `python scripts/reproduce.py --mode fit --origin 2024-09-01`.

## Состав

- `scripts/` — самостоятельный запуск финальной модели, интервалов и детекторов.
- `research/scripts/` — код исследовательских экспериментов и статистического аудита.
- `configs/` — фиксированные параметры моделей, разбиений и тестов.
- `data/` — исходная конкурсная таблица, подготовленная панель и внешние истории.
- `evidence/` — зафиксированные результаты и статистика, с которыми сравнивается новый запуск.
- `artifacts/` — архивы промежуточных результатов для повторения исследовательских расчётов.
- `deliverables/hackathon_report_latex/` — отчёт.

Данные СберИндекса сопровождаются исходной лицензией в `data/raw/hackathon/hackathonlicence/`.
