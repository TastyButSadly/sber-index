# СберИндекс: горизонтальный конкурсный отчёт

Основной исходник `main.tex` автономен: все графики встроены как редактируемые PGFPlots/TikZ, внешние картинки не нужны.

Сборка: `xelatex main.tex` два раза либо `tectonic main.tex`. Arial используется при наличии, иначе DejaVu Sans.

Структура: 36 страниц: 24 слайда основной истории, разделитель «Приложения» и 11 слайдов приложения. `point_metrics.csv` содержит метрики сохранённых прогнозов; `report_data.json` - численные данные графиков; `source_manifest.json` - SHA источников.

Новые модели при подготовке отчёта не обучались. Исходный набросок v4 сохранён отдельно. Полное досье: `reports/all_experiments_and_hypotheses.md` в исследовательском проекте. Русский текст подготовлен по sasha/deslop. Публикация и передача проекта не выполнялись.
